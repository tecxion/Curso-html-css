# 📚 Aprende HTML en 30 Días

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![License](https://img.shields.io/badge/license-MIT-green?style=for-the-badge)
![Progress](https://img.shields.io/badge/days-30-blue?style=for-the-badge)

Un curso completo y progresivo para aprender HTML desde cero hasta nivel avanzado en 30 días. Cada día incluye teoría, ejemplos prácticos y ejercicios con soluciones[web:11][web:16].

## 🎯 Objetivos del Curso

- Dominar todos los elementos y atributos HTML fundamentales
- Aprender HTML semántico y mejores prácticas de accesibilidad
- Crear páginas web estructuradas y optimizadas para SEO
- Desarrollar un proyecto web completo al finalizar el curso

## 📋 Requisitos Previos

- Un navegador web moderno (Chrome, Firefox, Edge)
- Un editor de código (VS Code recomendado)
- Conocimientos básicos de computación
- Ganas de aprender 🚀

## 🚀 Cómo Usar Este Repositorio

### 1. Fork y Clone

Haz fork del repositorio y clónalo localmente
```
git clone https://github.com/tu-usuario/aprende-html-30-dias.git
cd aprende-html-30-dias
```

### 2. Crea tu Rama de Trabajo

Crea una rama para tus ejercicios
```
git checkout -b mis-ejercicios
```


### 3. Completa los Ejercicios Diarios
Cada carpeta contiene la teoría, ejemplos y ejercicios del día. Trabaja en la carpeta `ejercicios/` de cada día.

### 4. Guarda tu Progreso

Añade y confirma tus cambios
git add .
git commit -m "Completado día X: [tema]"
git push origin mis-ejercicios
