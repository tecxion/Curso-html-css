Ejercicio 2: Mostrar Código HTML con Entidades

Objetivo: Aprender a mostrar código HTML en una página web usando entidades HTML para escapar los caracteres reservados.

Los caracteres <, > y & tienen significado especial en HTML y deben ser escapados.

1. Estructura Básica de HTML

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Primera Página</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>

2. Elementos Comunes de HTML

Código (con entidades)

<p>Párrafo</p>
<a href="#">Enlace</a>
<img src="foto.jpg" alt="Foto">

Resultado Visual

Párrafo

Enlace

3. Listas en HTML

<!-- Lista desordenada -->
<ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
    <li>Elemento 3</li>
</ul>

<!-- Lista ordenada -->
<ol>
    <li>Primer paso</li>
    <li>Segundo paso</li>
    <li>Tercer paso</li>
</ol>

4. Formularios HTML

<form action="/enviar" method="POST">
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
    
    <button type="submit">Enviar</button>
</form>

5. Caracteres Especiales en Código

Ejemplo de comparaciones:

Para mostrar: 5 < 10 && 10 > 5

Debes escribir: 5 &lt; 10 &amp;&amp; 10 &gt; 5

6. Tabla de Entidades Usadas

Carácter Entidad Descripción
< &lt; Menor que
> &gt; Mayor que
& &amp; Ampersand
" &quot; Comillas dobles
' &apos; Apóstrofo
